The ELOQUENT lab for evaluation of generative language model quality and usefulness addresses high-level quality criteria for generative language models through a set of open-ended shared tasks.

<!--more-->

## Tasks

The ELOQUENT Lab in its fourth edition features six different tasks:

{{< accordion  open_all="true" >}}
  {{< accordion-item title="Voight-Kampff" >}}
  Can machine-generated text be distinguished from human-authored text?
  {{< /accordion-item >}}
  {{< accordion-item title="Robustness " >}}
  Will a generative language model's output reflect cultural variety as represented in closely related varieties of languages? 
  {{< /accordion-item >}}
  {{< accordion-item title="Local Knowledge" >}}
  Will a generative language model's output reflect local knowledge from its training data in closely related varieties of language? 
  {{< /accordion-item >}}
  {{< accordion-item title="No Data" >}}
  Can a generative language model learn to handle a language without data, from a description of the language alone?
  {{< /accordion-item >}}
  {{< accordion-item title="Sensemaking" >}}
  Can a generative language model create a useful topical quiz from given text? Can it score responses to such quiz questions?
  {{< /accordion-item >}}
  {{< accordion-item title="Fluency" >}}
  Can a generative language model track human quality preferences for topically similar formulations?
  {{< /accordion-item >}}
{{< /accordion >}}
